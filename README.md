# Penny Pigeon ($PPGN)

Penny Pigeon is a community-driven meme token project on Robinhood Chain. We are building an ecosystem around the Penny character, combining community activities, digital content, and a playable browser game.

## Penny’s World

Penny’s World is our live browser-based rooftop farming game. Players can connect a wallet, grow crops, expand their garden, and save their progress.

The game is part of the wider Penny Pigeon ecosystem. Holding PPGN is not required to start playing.

## Current Stage

As of November 2026:

- Penny’s World is publicly playable.
